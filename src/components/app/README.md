# components/app

Komponen dasar aplikasi pelanggan (tema gelap landing, token `--a-*` di `styles/app.css`): `AppTheme` (provider Naive + `.app`), `AppHeader`/`AppFooter`, `AccountMenu` (menu ARIA), `AppField` (label+galat+aria), `PasswordInput`, `EventCard`/`EventCardSkeleton`, `Countdown`, `EmptyState`, `ErrorState`. Semua teks via i18n; tanpa emoji.

v2 (katalog): `HeroSpotlight` (carousel dapat dijeda), `FilterDock` (query-string), `EventRail`, `EventCard` (poster, blok tanggal, favorit), `FavoriteButton`, `TicketPanel` (tier, stepper, CTA per status).
